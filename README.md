# Neweix website starter

This is an initial static storefront landing page for Neweix.

## Files
- `index.html` — page structure and content
- `styles.css` — responsive visual design
- `script.js` — small mobile navigation behavior

## Important
This is a **visual starter only**, not a complete online store. Product catalogue, customer accounts, order processing, secure backend, database, admin dashboard and payment gateway are not active. Do not collect real customer details with this starter.

## Publish with GitHub Pages (preview only)
1. Upload these files to the root of `neweix24/neweix`.
2. Open the repository's **Settings**.
3. Select **Pages**.
4. Under Build and deployment, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then Save.

For the eventual production store, use a platform that supports the required backend and database (for example Cloudflare Pages + Workers + a database). Keep payment secrets on the server only, never in frontend files.
