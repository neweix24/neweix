# Ecosystem master architecture

The canonical and controlling Neweix ecosystem architecture is maintained in the Supreme repository:

[Supreme Ecosystem Governance and Operating Charter](https://github.com/neweix24/supreme/blob/main/docs/ecosystem-governance-charter.md)

This file is retained as a compatibility pointer for old links. It is not a separate blueprint and must not be edited to define conflicting authority, ownership, identity, payment, or service rules.

**Authority:** Supreme is highest and final. **Operations:** Admin conducts day-to-day operations within the Supreme-approved grant. **Neweix:** public hub and Admin entry point only. Each service owns its own data and business logic.
